Cutu's Adventure is a 2d top-down 3/4 rpg-like game.
It is a relatively new project but I am actively working on it
adding more stuff and trying to make a good game that I can someday put
on Steam. 
For now, it is still a prototype, but has some key elements of the gameplay. 
The game is developed in Code::Blocks 25.03 using SFML 3.0.2. 
Download my game from https://blockydev.itch.io/cutus-adventures.
